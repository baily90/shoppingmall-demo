# 商城项目需求文档

> 状态：已定稿
> 日期：2026-09-24

## 一、一句话定位

一个**综合电商**练习项目：多品类商品商城，含**管理端（Admin）**和 **H5 端（C 端）**，对标真实生产项目；本地开发跑通，后续可迁移阿里云。

## 二、核心功能清单

### 管理端（Admin）

| 模块 | 功能 |
|---|---|
| 登录 / 鉴权 | 管理员账号密码登录，完整 RBAC 角色权限（用户-角色-权限） |
| 分类管理 | 多级分类树，增删改查 |
| 品牌管理 | 品牌增删改查，关联商品 |
| 商品管理 | SPU/SKU、多规格、价格库存、图片上传（MinIO） |
| 订单管理 | 订单列表/详情、发货、状态流转 |
| 用户管理 | 查看/管理 C 端用户 |

### H5 端（C 端）

| 模块 | 功能 |
|---|---|
| 注册 / 登录 | 手机号 + 密码 |
| 首页 | 分类导航、商品列表 |
| 商品 | 详情页（多规格切换）、简单搜索/筛选 |
| 购物车 | 加购、改数量、选中结算 |
| 下单 | 收货地址、订单确认、mock 支付 |
| 订单 | 我的订单、状态查看、确认收货 |
| 个人中心 | 收货地址管理、基本信息 |

## 三、MVP 范围外（后置，明确不做）

- **微信生态**：公众号登录 / JSSDK / 小程序
- **真实支付**：先 mock（支付适配层留好接口，后续可换真实支付）
- **营销**：优惠券 / 满减 / 积分 / 秒杀
- **真实物流轨迹**：订单表只留「快递公司 + 单号」字段，不查轨迹
- **短信验证码**：C 端用密码登录，不接短信服务
- **评价 / 售后 / 退款**
- **搜索引擎**：先用 SQL 简单匹配，后置 ES
- **数据看板**：管理端图表统计（后置）
- **CICD / 云部署**：本地优先

## 四、技术底座（概要，细节见 `03-技术选型与接口清单.md`）

- 前端：React
- 后端：NestJS
- 运行时：Node v24.18.0
- 工程：pnpm Monorepo
- 基础设施：Docker 跑 PostgreSQL / Redis 7 / MinIO
- ORM：Prisma

## 五、关键决策记录

| 决策点 | 结论 |
|---|---|
| 商城定位 | 综合电商（分类 + 品牌 + 通用规格属性） |
| C 端用户体系 | 手机号 + 密码 |
| 营销功能 | MVP 不含，后置 |
| 订单履约 | 状态机 + 简化发货（保留物流单号字段，不查真实轨迹） |
| 权限控制 | 完整 RBAC（user / role / permission + 关联表） |
| 支付 | mock，接口抽象便于后续替换 |
| Node 版本 | v24.18.0 |
| 部署策略 | 本地优先，后续迁移阿里云 |
