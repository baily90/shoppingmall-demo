# 商城项目实施计划

> 状态：已定稿
> 日期：2026-09-24

## 贯穿原则

- **每阶段结束 commit 一次**，留可回退节点
- **跑通一个闭环再进下一个**，不恋战
- **阶段 3（交易闭环）是验收里程碑**，跑通即「商城成了」

---

## 阶段 0：工程地基

**目标**：搭好 monorepo 骨架和本地基础设施，跑通开发闭环。

**任务**
- 工程：pnpm workspace Monorepo（`apps/server` / `apps/admin` / `apps/h5` / `packages/shared`）；`docker-compose.yml`（PostgreSQL + Redis + MinIO）；ESLint + Prettier + husky + commitlint；`.env` 模板
- 后端：Nest 初始化；Prisma 初始化（`schema.prisma` 定义 19 张表 + migrate）；统一响应拦截器 + 全局异常过滤器 + 参数校验 Pipe；存储/支付适配层接口（空实现）
- 前端：admin / h5 各初始化 Vite + React

**完成标准**：`pnpm` 一条命令起三个应用；后端连上 Docker 三件套；Prisma 建出 19 张表；测试接口返回统一响应结构。

---

## 阶段 1：认证 + RBAC（第一个完整闭环）

**目标**：打通管理端登录和权限体系。

**任务**
- 后端：
  - `PrismaService` 封装
  - 管理端登录（JWT）+ C 端注册/登录（手机号 + 密码）
  - **JWT 双 token**：accessToken 无状态（短期）+ refreshToken 存 Redis（长期），登出删 refreshToken 实现失效
  - Passport JWT 策略；权限 Guard + `@Permissions()` 装饰器
  - RBAC seed（角色 / 权限 / 菜单初始化入库）
- 管理端：登录页、布局、路由守卫、动态菜单渲染

**完成标准**：管理员登录后菜单按权限渲染；无权限接口返回 403；C 端能注册登录；登出后 refreshToken 失效、accessToken 短期自然过期。

---

## 阶段 2：商品域

**目标**：商品是核心数据，管理端录入、H5 展示。

**任务**
- 后端：分类/品牌/商品 CRUD；SKU 矩阵生成（规格组 × 规格值笛卡尔积）；图片上传（MinIO）
- 管理端：分类管理、品牌管理、商品管理（多规格 + 传图）
- H5：首页、商品列表、商品详情（规格切换）

**完成标准**：管理端录入多规格商品 → H5 看到并切换规格、价格联动。

---

## 阶段 3：交易闭环（核心里程碑）

**目标**：打通购物车 → 下单 → 支付 → 发货 → 收货全链路。

**任务**
- 后端：购物车 CRUD；下单（校验库存、扣库存、生成订单 + 明细）；订单状态机；mock 支付（支付适配层实现）；订单管理
- H5：购物车、下单页、我的订单
- 管理端：订单管理（列表 / 详情 / 发货）

**完成标准**：加购 → 下单 → mock 支付 → 发货 → 确认收货，全链路跑通。

---

## 阶段 4：用户与地址

**目标**：补全 C 端用户中心和收货地址。

**任务**
- 后端：地址 CRUD
- H5：个人中心、地址管理

**完成标准**：下单可选地址，订单正确保存地址快照。
